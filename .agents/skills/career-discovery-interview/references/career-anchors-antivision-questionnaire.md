# Reference 2: Schein 职业锚 × 反愿景（时间排斥清单）参考问卷

本文件为职业规划快速访谈的**核心驱动力与负向边界测量锚点库**（基于 Edgar Schein 职业锚理论 Career Orientations Inventory [COI] 及反愿景 Anti-Vision 边界设计构建）。

> **核心原理**：学生直接填问卷选“想要获得什么”时，往往会勾选所有正面选项；只有通过**底线取舍（被迫放弃时最不愿妥协哪项）**与**反愿景排查（最痛恨把时间耗在哪类事情上）**，才能定位真实的内在锚点。

---

## 一、Schein 八大职业锚精简迫选锚点（实训基地情境版）

| 职业锚代码与名称 | 底层不可妥协诉求 | 经典问卷核心锚点陈述 | 实训基地典型投射表现 |
| :--- | :--- | :--- | :--- |
| **TF 专业/技术精进锚**<br>(Technical/Functional) | 「我要手里攒下硬核、可迁移的真本事」 | 如果一个岗位只让我开会协调、催进度，却学不到任何具体的技术/创作/专业手艺，我会觉得完全在浪费时间。 | 最关心能不能掌握 AI 编程工作流、分镜生图技巧、产品原型设计或数据分析硬技能。 |
| **GM 全局管理与统筹锚**<br>(General Managerial) | 「我想看懂组织和业务全局怎么运转并推动结果」 | 相比只埋头做一颗螺丝钉，我更想站在全局视角协调资源、制定规则、让一群人把事做成。 | 对基地正副总裁、秘书长、工作室主理人或跨部门治理改革感兴趣。 |
| **AU 自主与独立锚**<br>(Autonomy/Independence) | 「我要按自己的节奏、方式和审美做事」 | 我极度反感频繁打卡、事无巨细的流程束缚或必须时刻在线秒回；给我清晰目标，让我自己决定怎么做最高效。 | 偏好独立闭环小课题或异步提交，排斥高频会议与重度行政协调。 |
| **SE 确定性与凭证保障锚**<br>(Security/Stability) | 「我需要明确的规则、预期和可兑现的背书」 | 如果任务目标三天两头推翻重来、验收标准模糊不清，或者投入了时间却拿不到可验证的证明/结果，我会非常焦虑。 | 高度看重清晰的作业阶梯（课堂模式）与可兑现的证明/推荐信认定规则（注：因基地结业/证明细则可能处于社群立法草案演进期，Agent 须提醒此类学生首步先核对已生效的书面决议，严禁替未定标准打包票）。 |
| **EC 创业与从零创造锚**<br>(Entrepreneurial Creativity) | 「我想做出署自己名字、能在真实市场跑通的作品」 | 最让我兴奋的是把一个新点子变成真实上线的产品/内容，哪怕有风险，我也想看看真实用户买不买单、能不能赚到钱。 | 倾向「招聘模式（微型创业）」、独立游戏上架变现、新课研发或自媒体起号测试。 |
| **SV 赋能与助人价值锚**<br>(Service/Dedication) | 「我希望我做的事真能帮到具体的人」 | 看到同伴因为我的讲解少踩了坑、或者看到冷清的团队因为我的连接有了凝聚力，比单纯刷指标更让我有成就感。 | 适合助教、学习体验复盘官、新人破冰引导、用户反馈访谈。 |
| **CH 硬核挑战锚**<br>(Pure Challenge) | 「太简单的重复作业没意思，我想啃硬骨头」 | 照着现成答案抄一遍让我觉得无聊；越是别人搞不定、有技术或机制难度的卡点，越能激发我的斗志。 | 适合研究院攻坚、复杂工具链开发、解决组织信息断层等结构性难题。 |
| **LS 学业/生活平衡锚**<br>(Lifestyle Integration) | 「实训必须服从我现阶段的学业与核心主线」 | 现阶段我的专业课绩点、考研/保研/秋招或身心健康是第一位的；实训基地的投入必须可控、有明确边界，不能侵占主线。 | 需要固定每周小时数上限、考试周弹性静默机制与低耦合轻任务。 |

### 五组底线迫选题（Forced-Choice Trade-offs，访谈启发用）

当学生说“我都想要”时，选用其中 1–2 组贴近其处境的冲突情境提问：
1. **手艺 vs 统筹**：「如果未来一个月只能选一种收获：A. 独自打磨出一个能直接发给面试官试玩的完整小作品，但不管团队事务；B. 担任负责人统筹一个部门运转并推动一项制度落地，但自己没空写代码/做作品——你选哪个？」
2. **自主探索 vs 清晰阶梯**：「你更舒服的状态是：A. 给你一个参考答案和分步教程，一步步稳稳做完拿学分/证明；B. 只给你一个模糊的大方向，怎么干全由你自己定，可能做出彩也可能踩坑重来？」
3. **市场真刀真枪 vs 纯粹技术/内容打磨**：「做出来的东西，你更在意：A. 它在审美/技术逻辑上足够精致，自己看着满意；B. 哪怕粗糙一点，也要发到小红书/TapTap 上看真实路人点不点、愿不愿意付费？」
4. **单兵高效 vs 搭档共创**：「如果一个人干 3 天能做完 70 分，找搭档磨合分工可能要花 5 天、但也可能碰撞出你一个人想不到的 90 分（还可能遇到搭档掉链子），你现阶段更愿意选哪种？」
5. **投入上限底线**：「如果项目突然进入冲刺期，需要你连续两周每天额外多掏 2 小时，你会觉得『正好大干一场』，还是『绝对不行，已经越过我的学业/生活红线了』？」

## 二、「在实训基地想要获得什么」七大显性收益锚点

供访谈收敛时核对学生的真实获得感目标（具象化到可验证交付物）：

1. **作品集硬通货**：一个可公开访问的上线链接（网页/游戏/漫剧成片/GitHub 仓库），能直接放进简历或发给面试官。
2. **履历凭证背书**：正式的实训/实习证明，或由团队/导师背书的具体能力推荐信。
3. **AI 原生工作流手艺**：真正掌握用 AI Agent（WorkBuddy / Cursor / 元宝等）把想法落地的实操方法，跨过“脑子有想法但手跟不上”的门槛。
4. **商业与运营闭环体感**：走通一次从产品定位、定价、社媒宣发到真实用户反馈/销售提成的商业全流程（而不只是纸上谈兵）。
5. **互补同行者与协作经验**：找到 1–2 个靠谱、能力互补的搭档，体验真正的模块分工与合作开发，不再单机自嗨。
6. **组织治理与甲方出题能力**：锻炼需求拆解、规则设计、团队协调与给 AI/同伴“出好题”的管理能力。
7. **认知探索与低成本试错**：在不收学费、允许犯错的环境里，花最小代价试出自己到底适不适合某个方向（如产品、运营、编程、内容创作）。

## 三、「不想把时间花在什么事情上」反愿景排查表（Anti-Vision Checklist）

用于帮助学生明确划出**时间保护红线（Not-To-Do List）**：

- [ ] **T1 信息爬楼内耗**：每天花大量时间在几百条碎片语音/闲聊群消息里大海捞针找上下文。
- [ ] **T2 目标朝令夕改的返工**：需求没想清楚就开工，做到一半方向大变、前面白干。
- [ ] **T3 纯机械搬砖杂务**：没有方法论沉淀的重复复制粘贴、手工排版、催人填表打卡。
- [ ] **T4 孤岛式无效输出**：自己闷头做完交上去，既没有用户看、也没有导师或同伴给具体反馈。
- [ ] **T5 被迫社牛/硬推销**：让内向者去干陌生冷启动外联、公开发圈拉人头卖课。
- [ ] **T6 底层环境泥潭**：在没有业务产出的环境配置、账号资质报错、复杂工具链折腾上卡好几天。
- [ ] **T7 冗长无结论会议/公文抠字眼**：反复开没有议程的会，或在制度条文措辞上空转拉扯。
- [ ] **T8 替失联搭档无限兜底**：分工不清导致合作者中途消失，自己被迫背锅全包。
- [ ] **T9 侵占核心学业死线**：在期末考、论文答辩、关键比赛周被突发紧急任务打乱节奏。
