# Reference 1: Holland RIASEC × Bandura 自我效能四象限参考问卷

本文件为职业规划快速访谈的**能力-兴趣测量锚点库**（基于 Holland RIASEC 职业兴趣六维模型、O*NET Interest Profiler 精简维度，以及 Bandura 自我效能感理论构建）。

> **使用方式**：Agent **禁止**向受访学生逐题机械朗读打分；而是在对话中以本卷题目作为隐性诊断锚点，用具体情境启发学生，并将学生的自然语言回答映射至对应维度与象限。

---

## 一、Holland RIASEC 六维情境量表（实训基地映射版）

传统量表使用“1=非常不喜欢 … 5=非常喜欢”。在启发式访谈中，重点观察学生在面对以下 **6 类具体微情境**时的本能反应（眼睛发亮 / 愿意试 / 无感 / 生理性抗拒）：

| 维度 | 核心特质 | 经典问卷代表性情境题（原题锚点） | 量潮实训基地对应真实场景与任务 |
| :--- | :--- | :--- | :--- |
| **R 实操构建型**<br>(Realistic) | 动手搭建、工具驱动、即时可见的器物/系统反馈 | R1. 亲手配置工具、运行脚本或把一个能跑的网页/应用部署上线<br>R2. 对照报错信息或实际效果，一步步调试参数直到跑通<br>R3. 处理结构化数据清洗、格式转换或自动化流水线 | - 用 WorkBuddy / AI 跑通并上线小游戏网页<br>- 维护工具箱脚本、数据标注与清洗流水线<br>- 测试并修复产品交互 Bug |
| **I 研究探索型**<br>(Investigative) | 追问底层原理、抽象建模、独立拆解复杂未知问题 | I1. 探究一个现象背后的数学/博弈机制（如为什么这个玩法让人上瘾、那个制度会失灵）<br>I2. 阅读陌生代码库、技术文档或研究文献，搞清系统全貌<br>I3. 设计对比实验或评估指标来验证某个假设是否成立 | - 量潮研究院课题、Agent 工具链与工作流研发<br>- 拆解游戏数值引擎（如报童模型/信息博弈）<br>- 复盘学习摩擦清单、提炼方法论与教研规律 |
| **A 艺术创意型**<br>(Artistic) | 审美直觉、叙事张力、视觉/声音表达、反机械重复 | A1. 把一段文字故事转化为有情绪张力的画面分镜、条漫或短视频<br>A2. 设计网页/产品的视觉排版、配色、宣传册或背景音乐氛围<br>A3. 在既有框架上脑洞大开，衍生新剧情、新世界观或新角色设定 | - 小说部：用元宝/生图模型拆剧本分镜、做漫剧与关键帧<br>- 游戏部：替换故事外壳（如夜市改咖啡店）、美术与宣传册设计<br>- 实训基地社媒视觉/短视频内容创作 |
| **S 社会联结型**<br>(Social) | 同理心、教学赋能、破冰倾听、促进人与人连接 | S1. 把自己刚踩过坑学会的东西，用大白话讲给零基础新手听并帮他跑通<br>S2. 在冷清的群聊或小组里主动抛话题、接话茬，让大家愿意开口交流<br>S3. 倾听同伴的卡点或迷茫，帮对方理清头绪、协调分工配合 | - 课堂模式试学接力、未来付费班助教与答疑<br>- 社群破冰运营、新成员入群引导与体验收集<br>- 小组内沟通协调、同伴互助复盘 |
| **E 企业经营型**<br>(Enterprising) | 目标结果导向、商业敏感度、说服动员、资源整合 | E1. 思考“谁会真正为这个产品/课程掏钱”，设计定价、卖点与推广路径<br>E2. 代表组织对外联系高校社团、合作渠道或潜在用户谈合作<br>E3. 牵头组建小团队、拆解目标、推进排期并拿到可交付结果 | - 课程与游戏商业化推广（小红书/TapTap 引流、销售提成实战）<br>- 对接高校学生会建立校园招新“批发渠道”<br>- 担任工作室负责人、基地正副总裁统筹业务 |
| **C 常规秩序型**<br>(Conventional) | 结构化整理、规则严谨、索引归档、流程低摩擦运行 | C1. 把散落在群聊里的几百条讨论梳理成结构清晰的索引目录或知识库文档<br>C2. 起草格式规范的提案、验收标准、交接清单或台账记录<br>C3. 检查流程漏洞、跟进截止日期，确保团队按既定规则有序运转 | - 秘书处：建设与维护实训基地「第二大脑」索引与归档<br>- 代表大会/书记处：程序性立法、决议模板、实习证明核验<br>- 代金券账本、成员分流公示与考勤台账管理 |

## 二、Bandura 自我效能感 × 内在兴趣 四象限鉴别问卷

当学生在问卷或对话中表示**「我不擅长某事」**或**「我不知道自己擅长什么」**时，参考以下 **4 道鉴别题**拆分“能力感（Self-Efficacy）”与“意愿度（Intrinsic Interest）”：

### 鉴别题组（Diagnostic Items）

1. **暴露度检验（Exposure vs. Assumption）**
   - *原题*：「对于你觉得自己『不擅长』的这件事，你是曾经完整尝试过至少 2–3 次但结果不理想，还是因为看到专业术语/别人的成品觉得门槛太高，还没真正动手试过？」
   - *判别意义*：未尝试过的“不擅长”通常是**陌生感与距离感**，而非能力短板。

2. **脚手架敏感度检验（Scaffolding Test）**
   - *原题*：「假设现在给你一个已经跑通 80% 的半成品模板，外加 AI 手把手教你改其中一小块（30 分钟内就能看到自己的改动生效），你内心是『那我挺想试试看』，还是『哪怕喂到嘴边我也完全不想碰』？」
   - *判别意义*：前者属于**高意愿 × 低自我效能（新手恐惧）**；后者属于**真实低意愿（排斥项）**。

3. **过程能量检验（Flow vs. Drain during Struggle）**
   - *原题*：「回想一次你做某件事遇到卡壳的时候：解决它的过程让你觉得像在『打游戏解谜（虽然累但解开很爽）』，还是像在『填无意义的表格（每一秒都在内耗拖延）』？」
   - *判别意义*：区分值得投入刻意练习的**成长区**与应当止损的**消耗区**。

4. **伪优势识别检验（Competence Trap / Burnout Check）**
   - *原题*：「有没有哪类活儿，别人总觉得你很靠谱、做得又快又好（比如写纪要、做排版、改代码、当组长催进度），但你自己心里其实已经做腻了，不想在实训基地继续把时间花在上面？」
   - *判别意义*：识别**高能力 × 低意愿（伪优势/工具人陷阱）**——传统能力测评最容易误判的区域。

### 四象限映射与干预处方

| 象限 | 兴趣意愿 | 自我效能/现有熟练度 | 诊断定性 | 实训基地行动建议 |
| :--- | :---: | :---: | :--- | :--- |
| **第一象限：核心优势区** | 高 | 高 | **压舱石能力** | 作为团队分工中的主力输出位，用来快速建立信任、换取筹码或带新人（助教/主创）。 |
| **第二象限：潜能破冰区** | 高 | 低 | **新手恐惧 / 待启发潜能** | **重点保护与启发对象**。匹配低门槛脚手架（如半成品克隆、小步试课），严禁过早自我劝退。 |
| **第三象限：伪优势消耗区** | 低 | 高 | **精力黑洞 / 工具人陷阱** | **严格设限（不超总精力 15%）**。除非用来短期交换关键资源，否则拒绝长期承接此类角色。 |
| **第四象限：盲区规避区** | 低 | 低 | **非目标区** | **果断写入「不做什么清单」**。直接借助 AI 工具兜底，或寻找第一象限刚好在此处的互补搭档合作。 |
