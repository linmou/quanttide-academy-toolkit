## 一、极短单问号提问示例（≤ 60 字，严禁连带追问）

### 0. 飞书文档盘点与知情授权询问（`Phase 1.0`，开场或 `ask_question` 控件）
> **原则**：先用 `discover_feishu_docs.py --mode discover` 盘点出文档标题与对应的题目诊断用途，**绝不静默读全文**；请用户勾选授权后再读取。

- **示例（控件/开场授权询问）**：
  「刚盘点到几类飞书文档可帮咱们贴着真实实训场景聊（全程仅留你本地）：
  - **B. 部门任务书与方案**（如小游戏修订、晋江小说、小红书推广、第二大脑边界刻画）→ 用来对齐你感兴趣的真实任务与破冰切口
  - **C. 个人实训工作日志/汇报**（如《工作日志》《工作汇报》）→ 用来直接定位你做起来最来劲的充能点与实战复盘
  - **D. 会议纪要与研讨区** → 用来排查你最烦的协作痛点与时间红线
  - **A. 公共章程/第二大脑** 或 **E. 个人文档库归档（需单篇指定）**
  你允许我看哪几类或哪几篇文档？」

### 1. 开场与模式分流（`B1` / `A1`）
- **示例 1（松弛平视）**：「这儿聊的所有内容都只存在你本地电脑里。对于这阶段在基地想拿走什么，你心里已经有大致想法，还是正一头雾水想从零理一理？」
- **示例 2（结合已授权《工作日志》直奔主题）**：「刚看了你授权的 AI 编程《工作日志》，从复刻串串摊到自己加咖啡馆随机事件特来劲——接下来你已经有新目标，还是咱们顺着这份体感理一理下一步？」

### 2. 揉入已授权飞书文档或群聊场景的共鸣提问（`B3` / `A2`）
> **原则**：优先从用户授权读取的飞书任务书/工作日志（`discover_feishu_docs.py --mode fetch`）或群聊采样（`sample_feishu_scenes.py`）中提炼「那一类熟悉的事」，触发会心一笑的 Aha 感。

- **示例 1（结合已授权的部门任务书）**：
  「对照刚看的几份基地任务书，下面三类活儿你第一反应最想上手哪一种？
  - 拿现成小游戏模板改出一版带新事件和新 BGM 的可玩网页
  - 像“盲盒体验官”一样试用第二大脑，把看不懂的边界梳成清晰说明
  - 策划小红书“AI初创日常”引流帖或提炼小说发行卖点」
- **示例 2（已有方向者测核心发力点）**：
  「看你在日志里写“从用户变成拥有自己的网址成就感很具体”——这一块里，哪步操作是你现在最顺手、做完还特提神的？」

### 3. 「新手恐惧 `Q2`」与「熟手苦差事 `Q3`」必须分两轮独立短问
- **❌ 错误示范（严禁把长板、挑战、排雷揉成一团）**：
  *“对照组织诊断和搭工具这两块，哪部分是你顺手的长板，哪部分是你最想突破的挑战？顺便也排个雷——有没有哪类别人常找你兜底、但你这次绝不想再耗进去的熟手苦差事？”*
- **✅ 正确拆法 A（测 `Q2` 潜能脚手架）**：
  「你刚提到怕自己代码底子弱——要是给你一个跑通八成的半成品模板、让 AI 手把手带你改一小块，你会想试试，还是依然完全不想碰？」
- **✅ 正确拆法 B（下一轮单独测 `Q3` 伪优势排雷）**：
  「反过来排个雷：以前有没有哪类活儿别人总夸你靠谱、爱塞给你干，但这次在基地你绝对不想再碰了？」

### 4. 底线迫选（当学生什么都想要、但每周预算只有 3–5 小时）
- **示例 1**：「在每周 4 小时的上限下，如果这半个月只能保住一样：你是更想先攒出一个能写进简历的独立小作品，还是先跑通一次真实推广看路人买不买单？」
- **示例 2**：「你现阶段更享受哪种节奏：自己一个人关起门 3 天干脆利落跑通闭环，还是花点磨合时间找一位互补搭档碰撞出更大的东西？」

### 5. 实战复盘校准（`Mode C`）
- **示例 1（对照验真）**：「距离上次定下那个 2 周小实验过了一阵子——这段时间真干下来，哪个瞬间比你预想的更来劲，或者比预想的心累？」
- **示例 2（区分阶段波动与底层迁移）**：「这次想收一收节奏，主要是最近赶上考试/大作业周分身乏术，还是试过之后发现这类活本身就不对胃口？」

## 二、1 轮客观硬约束 & 反愿景快选卡示例（`B6` / `A4`）

为了不在客观账本上耗费 4–5 轮碎问，可在进入目标取舍前发一张清爽的快选小卡片（若宿主支持 `ask_question` 多选控件也可直接调用）：

```markdown
先花 20 秒对一下你的客观时间账本（直接回数字或关键词就行）：

1. **每周净时间**：扣掉课业和休息，每周能稳掏几小时给基地？（`A. 2-4h` / `B. 5-8h` / `C. 10h+`）
2. **出没形态**：主要是 **整块时间**（如周末/晚间连着 2-3h），还是 **零碎时间**（课间半小时）？
3. **近期封锁周**：未来 4 周有没有考试、论文、比赛等绝对不能被打扰的时段？
4. **最烦的 2-3 个雷区**（直接挑代号）：
   `① 爬几百条群消息找上下文` ｜ `② 目标朝令夕改白干` ｜ `③ 纯机械排版催表`
   `④ 做完石沉大海没反馈` ｜ `⑤ 被迫社牛硬推销` ｜ `⑥ 配环境报错卡几天`
   `⑦ 无议程同步长会` ｜ `⑧ 替失联队友背锅兜底`
```

## 三、私密原话 → 公开名片 `Avoid` 中性脱敏示例

| 学生在私密访谈里的真实原话（仅留存 `profile.md`） | 转写到公开名片 `partner-card.md` 的 `Avoid` 表述 |
| :--- | :--- |
| “我就是冲着拿份实习证明来的，每周最多掏 3 小时，别拉我天天开会扯皮。” | 倾向目标清晰、验收标准明确的模块化任务；暂不参与高频同步长会与边界未定的漫谈。 |
| “以前在学生会天天帮人改公众号排版、催大家交表，早干吐了，千万别再让我干这种打杂活。” | 暂不承接日常手工排版、行政催表打卡等重复性事务工作，聚焦核心模块共创。 |
| “我是纯社恐，让我去小红书发帖吆喝或者找外校社团拉人头我宁可退群。” | 暂不负责陌生冷启动外联与公开发帖拉新，更适合在幕后把产品逻辑或内容质量打磨扎实。 |
| “上次组队被队友鸽惨了最后全是我一个人熬夜擦屁股，没对齐分工前我不干。” | 重视开工前先对齐小目标范围、各自边界与共同署名方式，偏好异步留痕推进，不接职责模糊的兜底包干。 |
